# Meu Primeiro PR

Este repositório é um espaço de prática para aprender o fluxo de Pull Requests no GitHub.

## Sobre

Esse projeto foi criado para pratcar como:

- Criar uma branch
- Fazer alterações
- Abrir um Pull Request
- Fazer o merge

## Como contribuir

1. Crie uma branch a partir da `main`
2. Faça suas alterações
3. Abra um Pull Request explicando o que mudou
